Perguntas frequentes

O que é o Fable 5?

Fable 5 é o modelo de fronteira mais avançado da Anthropic. Focado em raciocínio profundo, trabalho agêntico de longa duração e programação em nível profissional. Oferece raciocínio de ponta e capacidades de extended thinking para problemas complexos.

Qual é a diferença entre Fable 5 e Opus 4.8?

Fable 5 é a próxima geração de raciocínio, com foco em agentes autônomos e programação avançada. Opus 4.8 continua sendo um modelo robusto de propósito geral. Fable 5 é melhor para tarefas que exigem análise profunda; Opus 4.8 é ideal para conversas gerais e processamento rápido.

O que é a variante [1m]?

[1m] refere-se à variante de 1 milhão de tokens do Fable 5. Permite trabalhar com repositórios inteiros, conversas longas e centenas de arquivos simultaneamente. Ideal para análise de código complexa e agentes de longa duração.

O que é extended thinking?

Extended thinking é uma capacidade que permite ao modelo pensar profundamente antes de responder. O modelo explora múltiplos caminhos, valida hipóteses e refina seu raciocínio. Perfeito para problemas complexos que exigem análise cuidadosa.

Como usar Fable 5 no Claude Code?

Use o comando /model fable para trocar para Fable 5 na conversa. Ou use a skill open source model-selector para seleção automática. Fable 5 está disponível no Claude Code CLI, web, IDE e versão desktop.
